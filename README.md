# Análisis de datos

## Descripción

Análisis estadístico de los datos de la encuesta utilizada para el trabajo práctico.

## Estructura

- data/: archivos CSV utilizados en el análisis.
- notebooks/: cuaderno de Google Colab.
- src/: código fuente auxiliar.
- output/: informe y resultados finales.

## Reproducción

1. Instalar Python 3.x.
2. Instalar las dependencias:

pip install -r requirements.txt

3. Abrir el cuaderno:

notebooks/analisis_encuesta.ipynb

4. Ejecutar las celdas en orden.

## Datos

El archivo `encuesta_sucia.csv` contiene los datos originales.

El archivo `encuesta_limpia.csv` contiene los datos luego del proceso de limpieza.

## Resultado

El informe final se encuentra en:

`output/informe_final.docx`
